Frequently Asked Questions

How does atomic stock deduction work?

When an order is submitted, available stock is verified for every item. Only if all quantities are available does the order commit and deduct inventory in real time.

What happens when an order is cancelled?

Cancelling an order automatically restores all physical stock units back into active inventory.

How do returns work?

Returns can be requested on any delivered order. When approved, item quantities are credited back to active stock.
