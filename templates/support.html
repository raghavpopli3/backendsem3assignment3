Frequently Asked Questions

How does real-time stock allocation work?

When an order is created, the system performs an atomic two-pass check across database transactions. Stock is verified and immediately deducted from the warehouse inventory to guarantee that out-of-stock items cannot be double-ordered.

What happens when an order is cancelled?

Cancelling an active order automatically restores the physical stock count for every single line item back into the active product catalogue.

How do returns and refunds get processed?

Customers can file an RMA request for any delivered order. Once an administrator approves the return request via the Returns portal, the inventory is credited back and the order status is updated to 'returned'.

Can external services integrate with the API?

Yes! All endpoints adhere to consistent REST contracts. Visit the Interactive API Playground to inspect request payloads and test endpoints in real time.
